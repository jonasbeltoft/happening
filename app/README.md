# Happening

A new Flutter project.

## Development

Press `F5` or press Run -> Start Debugging, to start emulator with hot reloading.

To select/change emulated device, press `CTRL + SHIFT + P` -> `Flutter: Select device`

For detailed runtime data, see the Flutter sidebar. It can be opened through `CTRL + SHIFT + P` -> `Flutter: Focus on Flutter Sidebar View`

## Component library

This project uses the [shadcn/ui](https://sunarya-thito.github.io/shadcn_flutter/) port for Flutter.
There is an [llms-full.txt](https://sunarya-thito.github.io/shadcn_flutter/llms-full.txt) file available for agents.
